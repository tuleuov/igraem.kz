## 🛠️ Быстрый запуск

### 1. Требования
* Node.js v20+
* Docker & Docker Compose (опционально)

### 2. Быстрый старт через Docker (Docker & Docker Compose)

Сборка многоэтапного образа (Multi-stage build) и запуск связки PostgreSQL 16 + API Backend & Web Frontend:

```bash
# Запуск контейнеров в фоновом режиме со сборкой
docker compose up --build -d

# Просмотр логов приложения и состояния базы данных
docker compose logs -f api

# Проверка здоровья системы (Healthcheck)
curl http://localhost:3000/health

# Остановка и удаление контейнеров
docker compose down
```

Приложение доступно по адресу `http://localhost:3000/` (проверка здоровья: `http://localhost:3000/health`).

### 3. Запуск локально для разработки

```bash
# Установка всех зависимостей
npm run install-all

# Запуск Prisma БД
npx prisma db push
npx prisma db seed

# Запуск Бэкенда и Фронтенда
npm run dev
```

## 🔒 Безопасность и Дизайн-система

* **ИИН Валидация**: Алгоритмическая проверка 12 цифр ИИН Республики Казахстан.
* **Казахский язык**: Обозначение языка строго как **`Қазақша`**.
* **Формат дат**: Все даты отображаются строго с точечным разделителем (`14.10.2026`).
* **Дизайн**: Светлая мобильная дизайн-система в фирменных оттенках `#00B050`.
