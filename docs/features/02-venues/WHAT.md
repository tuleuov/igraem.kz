# SPEC-02 · Venues — Feature Description

> Feature code: **SPEC-02**  
> Module: `02-venues`  
> Platform: Igraem.kz — бронирование спортивных площадок (Казахстан)

---

## 1. Назначение фичи

Фича **Venues** предоставляет пользователям каталог спортивных площадок (grounds), доступных для аренды через мобильное приложение Igraem.kz. Пользователь может:

- просматривать список площадок с фильтрацией по городу, виду спорта и доступности;
- открывать детальную карточку площадки (расписание, стоимость, рейтинг, карта);
- сканировать QR-код у ворот для мгновенного check-in и разблокировки замка;
- оставлять отзыв (1–5 звёзд) после завершённой аренды.

Администраторы платформы управляют площадками через защищённые эндпоинты (JWT, роль `admin`).

## 2. Охват городов

| # | Город (KZ)   | Регион            |
|---|--------------|-------------------|
| 1 | Темиртау     | Карагандинская обл. |
| 2 | Қарағанды    | Карагандинская обл. |
| 3 | Астана       | г. Астана          |
| 4 | Алматы       | г. Алматы          |

Площадки хранят `latitude` / `longitude`. Привязка к городу выполняется административно при создании записи `Ground`.

---

## 3. Виды спорта

| `type` value   | Название       | Покрытие      |
|----------------|----------------|---------------|
| `football`     | Футбол         | Искусственное |
| `volleyball`   | Волейбол       | Прорезиненное |
| `basketball`   | Баскетбол      | Асфальт / зал |

Поле `Ground.type` — строка с enum-семантикой; валидация производится на уровне контроллера.

## 4. Затронутые модули и файлы

| Слой           | Файл / Модуль                                           | Роль                                                |
|----------------|---------------------------------------------------------|-----------------------------------------------------|
| Backend controller | `src/controllers/groundsController.ts`             | CRUD площадок, агрегация рейтинга, QR-lookup        |
| Mobile screen  | `client/src/screens/HomeScreen.tsx`                     | Каталог площадок, фильтры, карта                   |

## 5. Зависимости и интеграции

| Интеграция       | Назначение                                                    |
|------------------|---------------------------------------------------------------|
| **TTLock API**   | Удалённое и QR-разблокирование замка ворот площадки           |
| **Geolocation**  | Проверка нахождения пользователя в радиусе 50 м от ворот      |
| **JWT Auth**     | Защита admin-эндпоинтов и POST /reviews                       |
| **QR Scanner**   | Считывание `qr_code_token` для spontaneous check-in           |
