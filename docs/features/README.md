## ⚙️ Как пользоваться при написании кода

1. Открыть папку фичи, которую реализуешь.
2. Прочитать `WHAT.md` — что делает фича.
3. Прочитать `RULES.md` — бизнес-правила (invariants, edge cases, constraints).
4. Прочитать `DATA.md` — модели данных, типы, поля.
5. Прочитать `API.md` — эндпоинты, request/response, коды ошибок.
6. Прочитать `FLOWS.md` — последовательности действий (flowchart, sequence diagram).
7. Писать код и тесты, строго следуя этим файлам.
