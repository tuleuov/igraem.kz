## 1. Обзор предметной области

Модуль обеспечивает безопасную беспарольную аутентификацию пользователей Республики Казахстан через связку: **Номер мобильного телефона + 4-значный SMS OTP-код + 12-значный ИИН**. Валидация ИИН предотвращает повторные регистрации нарушителей и гарантирует персональную ответственность за сохранность спортивного инвентаря.

model User {

  role          String         @default("client") // 'client' | 'admin'

  banned_until  DateTime?
  password_hash String

  avatar_url    String?

## 3. Функциональные требования (Requirements)

### REQ-AUTH-01: Валидация формата казахстанского номера
* **Описание**: Номер телефона принимается в формате Казахстана `+7 (7XX) XXX-XX-XX` (строго 10 значащих цифр после префикса +7).
* **Критерии приемки**:
  - `Given`: Пользователь вводит номер `7771234567`.
  - `When`: Нажимает кнопку «Получить SMS код».
  - `Then`: Система форматирует номер как `+7 (777) 123-45-67` и отправляет запрос на генерацию OTP.
  - `Given`: Пользователь вводит невалидный номер (менее 10 цифр или код не 7xx).
  - `Then`: Кнопка отправки заблокирована, поле подсвечивается ошибкой.

### REQ-AUTH-02: Запрос одноразового кода (SMS OTP) и Защита от спама (Cooldown)
* **Описание**: Генерация 4-значного числового кода, отправка через SMS Gateway и запуск локального таймера на 60 секунд.
* **Критерии приемки**:
  - `Given`: Пользователь запросил SMS код.
  - `Then`: Включается обратный отсчет: *«Отправить код повторно через 0:59»*. Кнопка повторной отправки неактивна до достижения `0:00`.
  - `When`: Прошла 1 минута.
  - `Then`: Активируется кнопка *«Отправить код повторно»*.

### REQ-AUTH-03: Мгновенный вход зарегистрированного пользователя
* **Описание**: При подтверждении корректного OTP для номера, уже имеющегося в таблице `users`, сервер возвращает JWT-токен и профиль.
* **Критерии приемки**:
  - `Given`: Пользователь с номером `+77771234567` уже зарегистрирован в базе.
  - `When`: Вводит верный 4-значный OTP код `1234`.
  - `Then`: HTTP 200 OK, выдается JWT-токен (срок действия 7 дней), клиент сохраняет токен в `localStorage` и открывает главный экран карты.

### REQ-AUTH-04: Регистрация нового пользователя и сбор данных профиля
* **Описание**: Если номер не найден в базе, открывается шаг заполнения личных данных: «Имя Фамилия» и «12-значный ИИН».
* **Критерии приемки**:
  - `Given`: Новый номер телефона.
  - `When`: Введен верный OTP код.
  - `Then`: Клиент отображает форму: поля «Полное имя» и «ИИН (12 цифр)».

### REQ-AUTH-05: Строгая алгоритмическая валидация ИИН РК
* **Описание**: Проверка 12 цифр по официальному алгоритму Комитета по правовой статистике РК:
  1. Длина строго 12 цифр (`^\d{12}$`).
  2. Первые 6 цифр соответствуют реальной дате рождения (`ГГММДД`).
  3. 7-я цифра определяет век рождения и пол (`1..6`).
  4. 12-я цифра сверяется по алгоритму двух проходов весовых сумм $\pmod{11}$.
* **Критерии приемки**:
  - `Given`: ИИН `890918350184` (Корректный, 18.09.1989, мужской пол).
  - `Then`: Валидатор возвращает `isValid: true`, извлекает дату рождения и пол.
  - `Given`: ИИН с несуществующей датой (например, `950230350124` — 30 февраля).
  - `Then`: Валидатор отклоняет ИИН с ошибкой `«Некорректная дата рождения в ИИН»`.

### REQ-AUTH-06: Проверка статуса бана при авторизации
* **Описание**: Если пользователь забанен (`is_banned = true` и `banned_until > now()`), вход разрешается, но клиент блокирует доступ к функциям и принудительно открывает `BannedUserScreen`.
* **Критерии приемки**:
  - `Given`: Пользователь находится под активным баном.
  - `When`: Успешно авторизуется по SMS.
  - `Then`: В ответе API передается флаг `is_banned: true`, время `banned_until`, и клиент отображает блокирующий экран с обратным отсчетом.

## 4. Спецификация API Контрактов (DTO)

### Запрос авторизации / логина (`POST /api/v1/auth/login`)
```json
// Request
{
  "phoneOrIin": "+77771234567",
  "password": "optional_password"
}

// Response 200 OK
{
  "success": true,
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIsIn...",
    "user": {
      "id": "uuid-v4",
      "iin": "890918350184",
      "phone_number": "+77771234567",
      "full_name": "Арман Сериков",
      "role": "client",
      "is_banned": false,
      "banned_until": null
    }
  }
}
```

### Регистрация профиля (`POST /api/v1/auth/register`)
```json
// Request
{
  "iin": "890918350184",
  "phone_number": "+77771234567",
  "full_name": "Арман Сериков",
  "password": "strongPassword123"
}
```
